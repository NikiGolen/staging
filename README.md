# Portfolio Staging Repository

This repository contains staging versions of portfolio pages, experiments, and prototypes before they are moved into the production portfolio repository.

## Purpose

Used for:

- Testing new layouts and features
- Reviewing experiment pages before publishing
- Validating content, styling, and functionality
- Safely iterating before production deployment

## Status

🚧 Staging environment — content may be incomplete, experimental, or subject to change.

## Notes

This repository is not intended to represent the final portfolio experience. Production-ready work is moved to the primary portfolio repository after review.
